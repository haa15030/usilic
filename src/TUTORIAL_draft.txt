  1.　概要

    control+g (control キーと g キーを同時押下) で TUTORIAL の目次画面へ戻り、次に以下
    のキーでカーソルを移動し return キーを押せば内容を参照できます。

      control+p：カーソルを１行上へ
      control+n：カーソルを１行下へ

    また ';'、':' キーでそれぞれ一つ上、下の章に移動します。これらは一覧の前後の項目を
    開くキーなので、TUTORIAL 以外の一覧 (ls、LOCATE、USILIC 等) でも同じように使えます。

    1.1.　表記

    　キー

    　　　　　^H：controlを押しながら"h"
    　　　　^J^H：^J の後 ^H
    　　　　^J b：^J の後 'b'
    　　　　^J^Oe：^J の後 ^O の後 'e'
    　　　　　^M：return
    　　　　　^[：esc
    　　　　　^I：tab
    　　　　　␣：space
    　　　　^␣：controlを押しながら space (^@ と同じ)

    　用語

    　　　　　""：キーアサイン以外の文字入力
    　　　　　./：カレントディレクトリ（操作上は . でも可）
    　　　　../：親ディレクトリ（同じく ..）
    　　　　 ~/：ホームディレクトリ（"echo $HOME"^M で表示）
    　　[モード]：当該モード名
    　usilic(1)：usilicコマンド自体
    　　usilicrc：各種設定（^I で同ファイル選択後 "e" で編集可）
    　　　　「」：usilic(1)が出力するメッセージ
    　　　　PID：プロセスID
    　　　　file：ディレクトリおよび特殊デバイス以外のファイル
    　　　SHELL：仮想端末
    　　　suffix：拡張子
    　mode line：ステータス表示（画面最下行）

  2.　起動

    usilic(1) は下記のいずれかのモードで動作します。起動時の引数は ^I（SHELL では ^J^I）
    で表示される INFO 画面の「Boot options」で確認できます。

    2.1.　Pager

      file 引数 ("usilic file"^M) または引数無しの標準入力経由 ("usilic < file"^M 等) で
      起動した場合、usilic(1) は pager として動作します。
      複数の file 引数起動の場合は、"n"/"p" でそれぞれ次/前の file へ、"x"/"f" で最初/
      最後の file へ移り、"q" で終了します。
      Pager 起動では画面最下行に下記のようなステータス行（以下 mode-line）が表示されま
      す。

        /Users/usilic/.usilic/usilicrc 00030/00062 48% 1918 usilic-1.5b
        (1)　　　　　　　　　　　　　　(2)　　　　 (3) (4)　(5)

        (1)：モード名
        (2)：カレント行 / 総行
        (3)：カレントページ / 総ページ * 100
        (4)：表示サイズ
        (5)：バージョン表示

    2.2.　File Manager

      標準入力も引数も無い起動では、前回終了時の状態 (ディレクトリ、閲覧中の file) を復
      元します。前回終了時 usilic.1 を閲覧していた場合、mode-line は下記のようになりま
      す。

        usilic.1 01/66 43% 2000 (groff) /Users/usilic/.usilic/
        (1)　　　(2)　 (3) (4)　(5)　　 (6)

        (1)：モード名
        (2)：カレント行 / 総行
        (3)：カレントページ / 総ページ * 100
        (4)：表示サイズ
        (5)：プログラム名
        (6)：以前のモード

      以前のモード名は mode-line(6) に表示され、^G でそこへ移動します。

        /Users/usilic/.usilic/ 01/66 43% 2000 (ls) usilic-1.5b
        (1)　　　　　　　　　　(2)　 (3) (4)　(5)　(6)

      (1)の末尾が「/」かつ(6)が非反転表示の「usilic-1.5b」の場合（以下 (ls)）、^G の連打
      で以前のディレクトリと行き来します。
      ディレクトリ引数 ("usilic directory"^M) で起動した場合は、そのディレクトリの (ls)
      から始まります。

      2.2.1.　ディレクトリ移動

        (ls) で行頭が「d」(「drwxr-xr-x ...」等) かつ行末が「/」で終わっている行はディレ
        クトリです。 ^M を押すとそこへ移動し、「./」を選択 または ^Xd"."^M（後述 [DIR]）
        とすると、カレントディレクトリの表示内容が更新されます。

        ^J^C：カレントディレクトリへ移動
              ファイル閲覧中あるいは SHELL 稼働中であっても、カレントディレクトリの
              (ls) へ移動します。(ls) で再度 ^J^C とすると「./」を選択した場合と同様、
              表示内容が更新されます。

        ^J^K：親ディレクトリへ移動
              ^J^C と同じくファイル閲覧中あるいは SHELL 稼働中であっても親ディレクトリへ
              移動します。

         ^JN：N番目のディレクトリへ移動 (N は 0〜9)
              文字列表示上先頭の「/」（スラッシュ）を 0 からカウント後、N 番目の「/」に
              相当するディレクトリへ移動します。たとえば

                /Users/usilic/.usilic/data/

              での ^J2 は下記へ、

                /Users/usilic/

              ^J2 の代わりに ^J^K とした時は親ディレクトリ

                /Users/usilic/.usilic/

              へ移動します。
              (ls) 以外の画面では、カーソル行 (または mode-line) の文字列の先頭がスラッ
              シュの時、それを数えて対応するディレクトリへ移ります。たとえば
              ^Xf"~/.usilic/usilicrc"^M（後述 [FILE]）で usilicrc を参照後 ^X^F とタイプ
              した後、

                /Users/usilic/.usilic/usilicrc

              のカーソル行で ^J2 とすると

                /Users/usilic/

              へ移動します。

      2.2.2.　ファイル表示

          ^M：ファイル内容を表示
              行頭が「-」(「-rwxr-xr-x ...」等) の行は file（通常ファイル）です。^M で
              ファイルの内容が画面に表示され、file の suffix が usilicrc の FILE に設定
              されている場合、指定のプログラムの出力を表示します（ .gz ファイルを
              "gzip -dc" で表示等）。EXEC に設定されている suffix の場合は、そのプログラ
              ムを起動します。
              ファイルサイズが usilicrc の BUFFER で指定した値を超えた場合は、^O^M と同じ
              く画面に出る分だけ読み込む方法で開き、「Not enough buffer」のメッセージ
              が表示されます (いずれかのキーで消えます)。
              usilicrc の CODE の設定でバイナリと判定された file は、最初に見つかった制御
              コードと file(1) によるファイルの種類を表示します。ただし macOS では、画像・
              PDF、およびクイックルックが扱える種類 (.numbers .docx 等、後述) の file は、
              その表示の代わりにクイックルックで開きます。

        ^O^M：ファイルを１行ずつ読み込む
              このキーで file を選択した時は、行単位入力で表示分まで読み込みます (巨大な
              file やアーカイブの内容一覧向け)。アクセス履歴には残りません。
              LOCATE、DU、FILE、USILIC の一覧でも同じように使えます。

        ^[^M：制御コードをそのまま可視化
              0x7f および 0x20 未満の制御コードを、反転表示 (0x0d の場合は反転の「M」)で
              表示します。アクセス履歴にも残らず usilicrc の FILE 設定も適用されません。
              読み込み中は任意のキーで中断できます。LOCATE、DU、FILE、USILIC の一覧でも
              同じように使えます。
              いずれも ^G および ^J^J で、それぞれ元の一覧および以前の file へ戻ります。

        ^J^J：以前の file へ戻る
              (ls) での ^G と同じく、一つ前の file と行き来します。

           ␣：クイックルック (macOS)
              カーソル行 (選択があればその全部) の file を qlmanage(1) のプレビューで表示
              します。usilic(1) を起動した端末の ^C またはプレビュー画面を閉じれば終了し、
              usilic(1) へ戻ります。LOCATE、DU、USILIC の一覧、および ARC の内容一覧でも
              使えます。

      2.2.3.　ファイル操作

           .：現在行選択/非選択トグル
          ^␣：現在行選択/非選択トグル (FILE、DIR の一覧ではこちらのみ)
           ]：現在行選択ののち下の行へ
           [：現在行選択ののち上の行へ
         ^Oy：全行選択
         ^On：全行解除
         ^Ou：閲覧 [USILIC]
         ^Oc：複写 [CP]
         ^Om：移動 [MV]
         ^Or：削除 [RM]
         ^Jp：実行 [PROGRAM]
        ^J^P：一覧 [PROGRAM]

        (ls) では、行を選択するとアンダーラインが付加されて閲覧/複写/移動/削除/実行の対
        象となります (選択が無い時の閲覧/実行はカーソル行が対象)。ディレクトリを選択でき
        るのは一度に一つだけで、二つ目を選ぼうとすると「Cannot select multiple
        directories」と表示されます。
        同じ操作は LOCATE、DU、FILE (^X^F)、DIR (^X^D)、USILIC の一覧でも使えます。

        閲覧
          ^Ou ではそれらが一覧 [USILIC] に表示され、^M で開いた後は ; および : キーで前後
          のファイルへ移動します。^G で元の一覧へ戻ります。

        複写/移動
          ^Oc/^Om を押すと mode-line に「Destination? 」のプロンプトが表示されます。それ
          ぞれ複写先/移動先を入力し (相対パスはカレントディレクトリ基準、^W で以前のディ
          レクトリ名を挿入)、^M で実行します。処理は SHELL で行われ、成功すると複写先/
          移動先の (ls) へ移動し、処理後のファイルにはアンダーラインが付加されています。
          何も選択していない時は発動しません。

        削除
          ^Or のプロンプト「Delete? (y/n) 」で "y"^M とすると、選択したファイルを削除し
          ます。それ以外の入力では何もしません。

          読み出し専用等、パーミッションに違反する対象がある場合は「Permission denied」
          と表示し、処理を行いません。処理の経過は SHELL に残るので、^[s で確認できま
          す。

        実行
          ^Jp のプロンプトにはカーソル行 (選択があればその全部) の file 名が入った状態で
          表示されるので、その前にプログラム名を入力して ^M で実行します。usilicrc の
          PROGRAM に載っているプログラムは usilic(1) の画面を一旦抜けてそのまま実行し、
          終了後に元の画面へ戻ります。載っていないプログラムは SHELL で実行されます。エ
          ディター等端末設定が変わってしまうアプリを SHELL で起動してしまった場合は ^Os
          で SHELL を再起動してください。なお "usilic"で始まる場合は、PROGRAM に載ってい
          なくても usilic(1) 自身を端末上 (CUI) で起動し、終了後に元の画面へ戻ります。
          ^J^P の時は、今まで PROGRAM および SHELL で実行したプログラムのソート済みの一覧
          が表示され、さらに ^R で実行順の履歴が表示されます。

      2.2.4.　アーカイブ内容閲覧および展開 [ARC]

        下記の suffix を持つファイルを ^M で選択すると内容一覧が表示されます。(ls) 同様、
        どれかを ^M で選んで内容を閲覧する (中のアーカイブはさらにその内容一覧へ) か、また
        は .[] キーで複数選択後、^Oa により展開先を指定すればそこへ展開されます (選択が無
        ければ全体)。(ls) のアーカイブの行で ^Oa とした場合も全体を展開します。展開先の
        指定無しで ^M のみの場合は ~/.usilic/data/ へ展開されます。
        ␣ ではカーソル行の file を一時的に取り出してクイックルックで表示します。

        .tar .tar.gz .tgz .taz .tar.z .tar.bz2 .tbz2 .tar.xz .txz .tar.zst .tzst .lzh
        .zip .jar .rpm .deb .rar .7z

        内容一覧が取れないファイルは通常の file として開きます。.epub のように中身が既
        存の形式であるファイルは、usilicrc の ARCHIVE で別名として追加できます。

  3.　モード

    usilic(1) は新しいモードを起動する前に、現在の mode-line をスタックに積んだうえで表
    示を更新します(^G キーでは最後に積まれた表示に戻ります)。
    これらのスタックの内容は (ls) でディレクトリを指定するか、または ^J2 等でディレクト
    リを移動するとクリアされ、mode-line(6) の位置に「usilic-1.5b」の文字列を表示しま
    す。
    LOCATE、DU 等の一覧表示画面でディレクトリを選ぶと (ls) 画面になりますが、そこでさら
    にディレクトリを選んだ時も上記スタックがクリアされます。
    LOCATE 中の ^J^L のように、モード中でそのモードの発動キーを押した場合は、途中の履
    歴を捨てて (^G の戻り先は最初にそのモードを発動した場所のまま) 改めて発動します。

    3.1.　アクセス履歴 [HISTORY]

    　^R：履歴一覧を表示

      FILE、DIR、MAN、LOCATE、FGREP、EGREP、CUT の各プロンプトで ^R キーを押した場合は、
      入力順に保存された文字列で HISTORY リストを表示します (最新が最下行)。カーソル行
      で ^M を押すかそのまま文字を入力すると、その文字列がプロンプトに入ります。
      PROGRAM および SHELL から入力された文字列は PROGRAM リストに保存され、^R で実行履
      歴一覧が表示されます。
      一覧の画面で再度 ^R を押すと、ソート後に重複を除いた一覧と、入力順の HISTORY リス
      トとを切り替えます。EGREP と CUT では、最初の ^R で usilicrc の EGREP に書かれた
      正規表現の実例を先頭に並べた一覧 (カーソルは最後に使った正規表現の行) を表示しま
      す。
      履歴は ~/.usilic/history に保存され、次回の起動後も使えます。種類ごとに残す行数は
      usilicrc の HISTORY で指定します。

    3.2.　文字列検索 [FGREP][EGREP]

         ^S：逐次検索 (FGREP)
       ^J^S：拡張正規表現で検索 (EGREP)

      検索でマッチした文字列はハイライト表示され、^N/^P で次/前のマッチ文字列へ移動しま
      す。逐次検索では文字が入力されるたびにリテラルな (文字どおりの) 検索が行われ、^M
      で確定します。マッチしない時は「No String」と表示されます。
      EGREP は grep -E で検索します (macOS の BSD grep と Linux の GNU grep の両方で同じ意
      味になるものだけを挙げます)。主なメタ文字（特殊文字）は次のとおりです。

      位置・境界
         ^：行の先頭（例: ^A は行頭のAにマッチ）
         $：行の末尾（例: Z$ は行末のZにマッチ）
        \b：単語の境界（例: \bcat\b は「cat」単独にマッチし、「concatenate」にはマッチし
            ない）
        \B：単語の境界以外

      任意の文字・文字の集合（文字クラス）
            .：改行を除く任意の1文字
          [ ]：括弧内のいずれか1文字（例: [abc] は a, b, c のどれか1文字）
         [^ ]：括弧内の文字以外の1文字（例: [^0-9] は数字以外の1文字）
        [a-z]：範囲指定（例: [a-z] は小文字アルファベット、[0-9] は数字）
           \w：英数字とアンダースコア（[a-zA-Z0-9_] とほぼ同じ）
           \W：英数字とアンダースコア以外
           \s：任意の空白文字（スペース、タブなど）
           \S：空白文字以外の任意の文字

        数字は \d ではなく [0-9]、数字以外は \D ではなく [^0-9] と書きます。

      繰り返しの回数を表す（量指定子）
            *：0回以上の繰り返し（なくても良いし、いくつあっても良い）
            +：1回以上の繰り返し（最低1回は必要）
            ?：0回または1回だけ存在（あってもなくても良い）
          {n}：ちょうどn回の繰り返し（例: [0-9]{4} は数字4桁）
         {n,}：n回以上の繰り返し
        {n,m}：n回以上、m回以下の繰り返し

      グループ化と条件分岐（OR）
            |：OR（または）（例: cat|dog は「cat」または「dog」）
          ( )：グループ化。文字列を1つの単位としてまとめる（例: (ab)+ は ab の繰り返し）

      エスケープ処理（\）について
        \.：ドット文字そのものを検索
        \?：質問マークそのものを検索
        \(：丸括弧そのものを検索

      grep -E には、最短一致 (*? +?)、非キャプチャグループ (?: )、先読み・後読み
      ((?= ) (?! ) (?<= ) (?<! )) はありません。

      参考: 基本正規表現 (素の grep) では、一部のメタ文字を \（バックスラッシュ）付きで
      書く必要があります。usilic(1) の検索では使いませんが、他のツールで出会った時のため
      に挙げておきます。
               \+：1回以上の繰り返し (GNU grep のみ)
               \?：0回または1回 (GNU grep のみ)
        \( ... \)：複数の文字を一つにまとめる
          \{n,m\}：n回からm回の繰り返し

    3.3. バッファ/ファイル分割 [CUT]

    　^Cb：指定文字列でバッファを分割
    　^Cf：指定文字列でファイルを分割

      検索文字列を入力すると、表示中のバッファに対して拡張正規表現 (EGREP と同じ grep -E)
      による検索を行い、マッチした文字列を含む行でバッファ内容を分割したうえで、当該行の
      目次一覧を作成します。目次一覧の mode-line には「(egrep)」が表示され、^M で選ん
      だ部分を表示している時の mode-line には「CUT: 検索文字列」が表示されます。
      ^Cf ではファイル名を入力し、そのファイル自身を分割します。後述 [FILE] のアクセス
      履歴一覧では「ファイル名 "文字列"」で表示され、そこから選ぶと同じ分割をやり直しま
      す。TUTORIAL 自身もこの仕組みで章ごとに分割して表示しています。
      目次一覧の画面でも ^S / ^J^S で見出しを検索できます。

    3.4.　ディスク使用量 [DU]

    　^Jd：ディスク使用量をdu(1)で集計
     ^J^D：集計結果画面へ戻る

      ^Jd で DU モードを起動した場合、カレントディレクトリを対象に du(1) を実行し、サイズ
      順の一覧を表示します。集計中に ^G を押すと中断し、それまでの集計結果へ移動します。
      ^J^D の場合は既存の結果にアクセスするだけなので、カレントディレクトリを変更しても
      一覧は更新されません。
      DU の一覧で ^Jd を押すと、カーソル行のディレクトリ (file の場合はその親) で集計し
      直します。

    3.5.　ファイル位置検索 [LOCATE]

    　^Jl：locate(1) 用データベースを作成
     ^J^L：LOCATE

      mode-line のプロンプトで、例えば ".tgz"^M とすれば、システムに含まれる .tgz という
      suffix を持つ全ファイル名を表示します。プロンプトには前回の検索文字列が入っている
      ので、そのまま ^M とすれば再検索せずに前回の結果を表示します。
      ^Jl ではデータベースを作成 (更新) します。作成中に ^G を押すと中断し、それまでに
      作成したデータベースで検索できます。

    3.6.　マニュアルページ閲覧 [MAN]

    　^Jm：マニュアルページを表示
     ^J^M：閲覧履歴一覧を表示

      入力文字列が既存のページにマッチした場合、man(1)により当該マニュアルを表示します。
      ^J^M では履歴一覧から選択するか、または新たに入力された文字列に該当するマニュアル
      ページを表示します。

    3.7.　プログラム実行 [PROGRAM]

    　^Jp：プログラム名を入力
     ^J^P：実行履歴一覧から選択

      usilic(1) を一旦抜けて、program リスト (usilicrc の PROGRAM) にあるプログラムを実行
      します。^Jp キーで mode-line 行から新規に入力された program 名が、リストに載ってい
      ない場合は、後述の SHELL に画面を切り替えて、そこで実行します。^J^P では今まで実行
      したプログラム名のソート一覧を表示します。
      EXEC で起動したプログラム、およびクイックルックも、正常に終わった場合は「プログラ
      ム名 file 名」の形でこの一覧に残ります。

    3.8.　ファイル [FILE]

    　^Xf：ファイル名を入力
     ^X^F：閲覧履歴一覧から選択

      mode-line 行で入力、または今までにアクセスしたリストから選択したファイルを表示しま
      す。FILE のファイルリストでは、CUT で使用された文字列はダブルクォート (") で括って
      表示します。ただし ^O^M または ^[^M で選択したファイルは ^J^J キーや FILE リストで
      は表示されません。
      一覧で文字を入力すると、その文字列でカーソル行のパスを直接編集できます。そのため一
      覧での選択は ^␣ だけで行います。

    3.9.　ディレクトリ [DIR]

    　^Xd：ディレクトリ名を入力
     ^X^D：閲覧履歴一覧から選択

      mode-line 行で入力、または今までにアクセスしたリストから選択したディレクトリに移動
      します。^G でリストへ戻りますが、^J^C、^J^K、^J2 等のディレクトリ移動キーを入力す
      ると DIR モードからは離脱します。

    3.10.　文字列コピー [COPY]

    　^O^C：COPY モードを開始
      ^@ (^␣)：範囲指定開始/終了トグル
      ^X␣：矩形範囲指定開始/終了トグル
      ^[w：指定範囲をクリップボードへコピー
      ^[p：指定範囲をコピーして PROGRAM のプロンプトへ入れる
      ^O^Y：プロンプトの入力中にクリップボードの内容を挿入

      mode-line 以外の画面の文字列をクリップボードへコピーします。^O^C の後、^N/^P/^F/^B
      /^A/^E (または矢印キー) でカーソルを移動し、^@ で範囲指定を開始した後は、カーソル
      移動後のハイライト表示がコピー対象エリアとなります。一旦 ^@ で範囲指定を解除したあ
      とも、再度 ^@ により複数のエリアが作成され、同様の切り替えは ^X␣（矩形範囲指定）で
      も機能します。^[N (N は数字) で N 行目へ移動し、^G で COPY を中止します。
      作成された全エリアは ^[w でクリップボードへコピーされ、^O^Y でペースト可能です。
      macOS ではシステムのクリップボードにもコピーされるので、他のアプリへもペーストで
      きます。ただし「ユニバーサルクリップボード」が有効な場合は、同じ Apple アカウント
      の他の機器へも反映されてしまいます。予期せぬ文字列がペーストされる事態を回避したけ
      れば、「システム設定」⇒「一般」⇒「AirDropとHandoff」で「Handoff」を無効にしてく
      ださい。

    3.11.　ファイル編集 [EDIT]

     　e：usilicrc の EDITOR で編集

      ファイル名 (mode-line(1)) が file で、プログラム名 (mode-line(5)) が空白の時は
      usilicrc に定義されているエディターを起動します。
      カレント行番号 N を +N オプションでエディターへ渡して起動するので、同オプションが
      使用できるエディターを設定しておくと便利です。デフォルトでは vi(1) に設定してあり
      ます。

    3.12.　usilic(1) 情報 [INFO]

    　 ^I：主な情報を表示
     ^J^I：SHELL から発動

      usilic(1) に関する下記の情報を表示します。カーソル行で ^M を押すとその file を開き
      ます。

      Boot options：起動オプション
      Startup file：設定ファイル (usilicrc)
             ERROR：稼働中のエラーメッセージ
             SHELL：仮想端末からの出力
          TUTORIAL：この TUTORIAL
              WORK：作業ファイル (^X^W で保存したもの、および ARC の一時展開先)

      下記のキーで、それぞれを直接開くこともできます。

      ^J^Oe：ERROR
      ^J^Os：SHELL の出力
      ^J^Od：~/.usilic/data/ の (ls)
      ^J^Ow：WORK の一覧 (後述 [USILIC] の目次の WORK と同じ)

    3.13.　仮想端末 [SHELL]

      ^[s：SHELLへ移動
      ^Os：SHELLを再起動
      ^J.：カレントディレクトリへ移動
      ^J,：カレントディレクトリ一覧
      ^Jw：バッファ名 (file 名) をプロンプトに挿入
     ^J^W：バッファの内容を保存し、それを表示するコマンドをプロンプトに挿入
      ^[l：SHELL の出力を file として表示 (LOG)

      ^J. で SHELL プロンプトのカレントディレクトリを (ls) の位置に設定します（^J, では
      "ls -l" を実行）。^J^W ではバッファの内容を ~/.usilic/data/ (または WORK) に保存
      し、"cat ファイル名" をプロンプトに入れます。
      SHELL の中からは ^O/ で出力の検索、^O^F/^O^B でページ送り/戻し、^O^L で再表示、
      ^J^I で INFO を使えます。^G で元のモードへ戻ります。
      異常動作およびプログラム実行中によりプロンプトが戻っていない場合、CP や PROGRAM 等
      SHELL プロンプトを使用する機能および EXIT を実行しようとすると、SHELL 画面に切り替
      わります。
      SHELL プロンプトでパイプ（"ls | usilic"^M）または file 引数（"usilic file"^M）で
      usilic(1) を起動した場合は、それぞれファイル名「(stdin)」、「file」で内容を今の
      usilic(1) に表示し、directory 引数（"usilic directory"^M）ではそのディレクトリの
      (ls) になります。また "man bash"^M 等の出力は、一時的な PAGER 環境変数により
      usilic(1) へのパイプ入力へ切り替わるため「(stdin)」で表示されます。この機能では、
      モード切り替えで使用する socket(2) の認証に shell のプロセス ID を使用しているの
      で、SHELL プロンプトで su(1) 等を実行した場合、そのプロンプトからはモードが切り替
      わりません。(補足の章の socket(2) 参照)
      usilic(1) の SHELL は CP/MV/RM 等のファイル操作を行うために用意した仮想端末なので
      最小限の機能しかなく、エディタやページャ等、端末設定を操作するプログラムは正常に
      動作しません。ただしプログラム名が program リストに載っている場合は、PROGRAM に画
      面を切り替えて実行されます。そうでないプログラムを意図せず起動してしまった時は、
      キー入力で終了可能なら終了を、それ以外のケースでは ^Os により SHELL を再起動してく
      ださい。
      対応している shell は bash、zsh、tcsh、csh です (usilicrc の SHELL 参照)。

    3.14.　補完

      SHELL プロンプトの直後に ^I を押すと実行可能なファイルリストを表示します。これは環
      境変数 $PATH が示すディレクトリ下に配置された実行可能ファイル一覧です。どれかを選
      択するか、または入力された文字列にマッチする名称のプログラムが $PATH 上に存在する
      場合はカーソル位置に挿入され、複数の候補があればビープ音で通知します。さらに ^I で
      今度はそれらのリストが表示され、同じ手順によりプログラムの絞り込みが可能です。そう
      して確定したプログラム名に続き ␣ のあとの ^I ではカレントディレクトリの内容一覧が
      表示されるので引数の特定にも同じ手順を使用でき、^Jp（PROGRAM）および ^Jm（MAN）の
      プロンプトでも ^I による実行ファイル名補完は機能します。
      FILE および DIR では、$PATH 上の実行ファイル検索は行いません。カレントディレクトリ
      内の file およびディレクトリだけが補完の対象になります。

    3.15.　コマンド行

      mode-line のプロンプト、および行頭が「usilic-1.5b:」（一時的な PS1 環境変数）の
      SHELL プロンプトでは下記のキーが使用できます。

      ^H：カーソル位置から左へ１文字削除
      ^D：カーソル位置の文字削除
      ^K：カーソル位置から行末まで削除
      ^U：カーソル位置から行頭まで削除
      ^Y：カーソル位置に削除内容を挿入
      ^A：行頭へ移動
      ^E：行末へ移動
      ^B：左へ１文字移動
      ^F：右へ１文字移動
      ^[b：左へ１単語移動
      ^[f：右へ１単語移動
      ^[d：カーソル位置から右の１単語を削除
      ^[^H：カーソル位置から左の１単語を削除
      ^_：直前の編集を取り消す (undo)
      ^L：画面を再表示
      ^Q：機能キャラクタ入力
      ^W：^J^W、^Jw のコマンドを再表示(SHELL)
      ^W：以前のディレクトリ名を表示(CP/MV)
      ^I：ファイル名補完
      ^G：入力を中断 (SHELL では ^C)

      単語はASCII の英数字と、日本語等のマルチバイト文字の並びです。

    3.16.　アクセス履歴の一覧 [USILIC]

      ^[u：目次
     ^J^U：種類ごとの一覧
      ^Ju：時系列の一覧

      今までにアクセスした file、ディレクトリ、マニュアルページの履歴を一覧表示します。
      ^[u の目次には MAN、DIR、FILE、PROGRAM、WORK の見出しが並び、^M でそれぞれの一覧
      を開きます。PROGRAM の項目で ^M を押すと、その文字列が PROGRAM のプロンプトに入り
      ます。WORK は ^X^W で保存した作業ファイルの一覧です。
      ^J^U は種類を問わずソートした一覧、^Ju はアクセスした順 (最新が最下行) の一覧で
      す。一覧では (ls) と同じくファイル操作 (.[]、^Ou、^Oc 等) が使えます。
      ^Ou で開いた選択ファイルの一覧も、この USILIC の一覧です。

    3.17.　マクロ

      ^X(：キーボードマクロの記録開始
      ^X)：キーボードマクロの記録終了
      ^Xe：記録したマクロを実行

      ^X( から ^X) までに押したキーを記録し、^Xe で繰り返します。実行の間隔は usilicrc
      の WAIT で指定します。

    3.18.　HELP / TUTORIAL

       ^T：TUTORIAL を表示
       ^H：HELP を表示
     ^J^H：HELP を表示
      ^Ja：TUTORIAL の日本語/英語を切り替え

      TUTORIAL は章ごとに CUT で分割した目次から始まります (1章参照)。

    3.19.　EXIT

    　^X^C
    　^[^[

      mode-line に「EXIT (y/n)?」を表示し、"y"^M で usilic(1) を終了します。
      usilic(1) をディレクトリ引数で起動した場合、各モードを発動する際、前回終了時のカー
      ソル位置等の情報を ~/.usilic/history から読み取って同じ状態を復元します。モード終
      了時も次回発動のために同ファイルへ状態が保存され、usilic(1) 自体を起動する際も、標
      準入力無しかつ引数無しの時は、前回終了時の状態を復元します。
      それらのすべての履歴は単一の file ~/.usilic/history を介してやり取りするため、引数
      無しの usilic(1) を二重に起動しようとすると警告を表示します。
      SHELL busy の状態で SHELL 画面に切り替わった時は、プログラムを終了させてから ^X^C
      または ^[^[ キーで EXIT を再実行して下さい。

  4.　設定

    usilic(1) は起動時に ~/.usilic/usilicrc を読み込んで環境設定を行います。同ファイルが
    存在しなければ、インストール先の ~/.local/lib/usilic/usilicrc (または
    /usr/local/lib/usilic/usilicrc) を読み込みます。自分用に変更したい時は、それを
    ~/.usilic/ へコピーして編集してください。
    書式の誤り等は ERROR (^J^Oe) に記録されます。英語のコメント付きの同じ内容のファイル
    が usilicrc.en です。

    以下は usilicrc で定義されている内容です。

    ARCHIVE
      書式：suffix0　 suffix1
      用例：.epub　　 .zip
      内容：

      組み込みのアーカイブの suffix1 に、新しい suffix0 を別名として追加します。一覧の
      取り方や取り出し方は形式ごとに組み込まれているので、新しい形式を定義することはで
      きません。組み込みの suffix1 は下記のとおりです。

      suffix1　 program
      .tar　　　tar tvf
      .tgz　　　gzip -dc | tar tvf -   (.tar.gz .taz .tar.z も同じ)
      .tar.bz2　bzip2 -dc | tar tvf -  (.tbz2 も同じ)
      .tar.xz　 xz -dc | tar tvf -     (.txz も同じ)
      .tar.zst　zstd -dc | tar tvf -   (.tzst も同じ)
      .lzh　　　lha
      .zip　　　unzip -l               (.jar も同じ)
      .rpm　　　rpm -qplv
      .deb　　　ar tv
      .rar　　　lsar -l
      .7z　　　 7z l (7z が無ければ 7zz)

    FILE
      書式：suffix program (option)
      用例：.gz　　gzip　　-dc
      内容：

      program を実行して suffix を持つファイルの内容を平文表示。

    EXEC
      書式：suffix program (option)
      用例：.info　info　　-f
      内容：

      suffix を持つファイル引数で program を実行。macOS でアプリで開く時は open を使いま
      す (例: .mp4 open、アプリを指定する時は .mp4 open -a IINA)。

    EGREP
      書式：string
      用例："^  [0-9]+\."
      内容：

      EGREP および CUT(正規表現) の ^R で、一覧の先頭に表示する正規表現の実例。空白を含
      む string は "" で囲みます。以前の節名 GREP も使えます。

    PROGRAM
      書式：program (option)
      用例：less
      内容：

      PROGRAM で起動する program のリスト。ここに載っている program は SHELL ではなく、
      usilic(1) の画面を一旦抜けて実行されます。

    EDITOR
      書式：editor
      用例：vi
      内容：

      EDIT で起動されるエディター。

    BUFFER
      書式：size
      用例：64
      内容：

      file を読み込むバッファの最大 size (MB、1〜100、デフォルト 64)。これを超える file
      は ^O^M と同じく画面に出る分だけ読み込む方法で開きます。

    CODE
      書式：code0 code1 ...
      用例：1　　 8　　 ...
      内容：

      ここでの設定以外の 0x20 未満の制御コードが、FILE・EXEC の suffix を持たない file
      に含まれていれば、バイナリファイルとみなして file(1) を実行し、該当コードとファイ
      ルタイプを表示。code0 が 0 ならこの判定をしません。判定は file の先頭 64KB で行い
      ます。

    SHELL
      書式：shell
      用例：tcsh
      内容：

      SHELL モードで起動する shell。環境変数 SHELL が bash、zsh、tcsh、csh のどれかなら
      そちらが使われ、ここの設定はそれ以外の時だけ使われます。ここにも設定が無ければ
      bash を使います。

    HISTORY
      書式：line
      用例：500
      内容：

      履歴 (FILE、DIR、MAN、LOCATE、FGREP、EGREP、SHELL のコマンド) を種類ごとに残す最大
      の line。これを超えると古い行から消えます (USILIC はその 3 倍)。0 は無制限です (デ
      フォルト)。

    WAIT
      書式：wait
      用例：10
      内容：

      キーボードマクロを wait (10 msec) 間隔で実行。

    LS
      書式：flag
      用例：1
      内容：

      ls 表示の形式 (起動後は ^Oo で切替) の初期値。セットされている時は、ファイル名の
      み表示。

    SCROLL
      書式：flag
      用例：1
      内容：

      スクロールモードの初期値。セットされている時は、最下行より上の範囲でスクロール。

    COLUMN
      書式：width
      用例：8
      内容：

      (ls) で、ファイル名に使える表示幅がこの値未満になる狭い画面では、自動的にファイル
      名のみの表示に切り替えます (デフォルト 8)。

    CP
      書式：cp (option)
      用例：cp -vRi
      内容：

      CP の cp(1) のコマンド。(デフォルト: cp -vR)

    MV
      書式：mv (option)
      用例：mv -vi
      内容：

      MV の mv(1) のコマンド。(デフォルト: mv -v)

    RM
      書式：rm (option)
      用例：rm -vri
      内容：

      RM の rm(1) のコマンド。(デフォルト: rm -vr)
      -i を付けた場合、確認は SHELL で行います (^[s で SHELL へ移動して答えます)。

    KEY
      書式：F-n　キー　　(接頭キー F-0〜F-4 の定義)
      　　　K-n　キー　　(機能 K-n のキー)
      用例：K-65　ESC ESC
      内容：

      キーの割り当て。K-n の番号は機能ごとに固定の ID で、行の順序には意味がありませ
      ん。キーを変えると、その機能は新しいキーでだけ動きます。キーを空にすると、その機
      能は割り当て無しになります。キーは C-x (Ctrl+x)、ESC、SPC、F-n (接頭キー)、その 1
      文字で書きます。詳しくは usilicrc の KEY の説明を参照してください。

  5.　起動オプション

    usilic [-c|-g] [-f font] [-u usec ...] [-i pixel ...] [<file] [file ...] [directory]

    -c：端末上 (CUI) で起動
      端末から起動した時のデフォルトです。

    -g：GUI のウィンドウで起動 (後述 6章)
      macOS で、Finder から usilic.app を開いた時 (端末が無い時) は、指定が無くても
      GUI で起動します。-c と -g は同時に指定できません。

    -f font：GUI で使うフォントファイル
      例: -f /Library/Fonts/MS-Gothic.ttf
      一度指定すると ~/.usilic/history に記憶され、次回から (Finder からの起動でも) そ
      のフォントを使います。指定が無い時は、起動した端末のフォントに合わせます。

    -u usec ...：慣性スクロールの速度
      慣性スクロールの 10 段階の速度を、遅い方から順に、1 行進むごとの待ち時間 (マイク
      ロ秒) で指定します。指定した個数の段階だけが置き換わります (例: -u 90000 55000
      30000 15000 は遅い方から 4 段階)。値が小さいほど速くなります。

    -i pixel ...：慣性スクロールに移るドラッグの距離
      マウスのドラッグを離した時、慣性スクロールの何段目の速度で動き出すかを決める距離
      (ピクセル) を、1 段目から順に指定します。例えば -i 20 40 80 160 320 では、離す直
      前の動きが 20 ピクセル未満なら止まり、20〜39 なら 1 段目、... となります。

    -h：使い方 (usilic [<file] [file] [directory]) を表示して終了

    -m file、-n file：ドキュメント作成用
      usilic 独自の装飾タグ (<b> <u> <i> <indentN>) で書かれた file (QUICK.txt 等) を、
      -m では重ね打ちの平文 (HELP 形式) に、-n では groff -ms のソースに変換して標準出
      力へ書き出し、終了します。

  6.　GUI (-g)

    6.1.　起動と切り替え

      -g で起動すると、usilic(1) は端末とは別のウィンドウで動作します。起動した端末のフォ
      ント・文字の大きさ・配色 (Terminal.app、iTerm2、GNOME Terminal、Ptyxis) に合わせ、
      端末のウィンドウと同じ位置・大きさで開きます。
      ^Og で端末 (CUI) の表示と GUI のウィンドウとを行き来します。
      ウィンドウを閉じるか、起動した端末で ^C を押すと終了します (pager として起動した
      時も同じ)。

    6.2.　表示

      Cmd + "="：文字を大きく
      Cmd + "-"：文字を小さく
      Cmd + "0"：文字の大きさを元に戻す
      Cmd + "k"：配色の切り替え (黒地に灰、黒地に緑、黒地に琥珀、白地に黒)

      ウィンドウの大きさを変えると、行数・桁数もそれに合わせて変わります。右端のスクロ
      ールバーのつまみをドラッグすると、その位置へ移動します。

    6.3.　マウス

      マウスを動かすと、ポインターの下の行がカーソル行になります。カーソル行をクリック
      すると ^M と同じく開き、他の行をクリックするとその行へカーソルが移ります。
      画面をつかんでドラッグするとスクロールし、動かしながら離すと、その勢いに応じた速さ
      で慣性スクロールが続きます。慣性スクロール中にクリックすると止まり、その時のカー
      ソル行を選びます。
      マウスホイールでも慣性スクロールします。同じ向きに回すと速く、逆に回すと遅くなり
      ます。慣性スクロール中の ↑/↓ でも速さを変えられます。
      速さは -u、動き出しの距離は -i で調整できます (5章)。

    6.4.　ファイルのドロップ

      Finder から file をウィンドウへドロップすると、その file を開きます (ディレクトリ
      ならその (ls))。複数の file をドロップした場合は、^Ou と同じ一覧にして最初の file
      を開きます。Finder の「このアプリケーションで開く」で usilic.app を選んだ場合も同
      じです。

    6.5.　端末でのマウス

      CUI でも、マウス操作をアプリへ伝えられる端末 (Terminal.app、iTerm2 等) では、ドラ
      ッグによるスクロールと慣性スクロールが使えます。また Shift + ↑/↓ で慣性スクロール
      を開始します。

  7.　補足

  環境
    usilic は起動時に ~/.usilic/ (設定・履歴等) と /tmp/.usilic.PID/ (作業用) のディレ
    クトリを作成します。~/.usilic/ には下記の file が置かれます。

      usilicrc：自分用の設定 (4章)
       history：履歴、カーソル位置等
         error：ERROR の内容
         shell：SHELL の出力 (LOG)
         data/：^X^W で保存した file、ARC の展開先等

    usilic(1) は今の端末が SHELL かどうかを判別するのに "USILIC" 環境変数を使用していま
    す。この変数が定義されている端末 (SHELL の中) で usilic(1) を起動すると、元の
    usilic(1) の画面に表示します。

    pager で使用する場合は、端末で一旦 "export PAGER=usilic"^M としておけば man(1) 等の
    出力を usilic(1) で参照できます。

    macOS では、最初の起動時に、使う機能に必要で未インストールのプログラム (groff、
    mg、texinfo、sevenzip) があれば、SHELL のプロンプトに "brew install ..." を入れた
    状態で止まります。^M で実行し、終わってもまだ足りないものがあれば、その分だけのコ
    マンドが再び入ります (Ubuntu では "sudo apt install -y ...")。

  環境変数
    USILICCHARSET：表示の文字コード (euc、ascii 等) の指定
       USILICFONT：GUI のフォントファイル (-f と同じ、ただし記憶はしない)
           PAGER：上記参照

  漢字コード
    UTF-8、EUC-JP、Shift_JIS、JIS (ISO-2022-JP) の file は、内容をバッファに読み込ん
    だ後、端末の文字コードに変換して表示します。それに伴い、mode-line(4) (表示サイズ) が
    実際のファイルサイズとは異なって表示される事があります。

    ^O^M でファイル表示した場合や usilic(1) を pager で起動した時は、入力行毎に、判別お
    よびコード変換を行いますが、行内に１バイト半角カナが多用されている場合などは、正常に
    判別できない場合があります。

    ^[^M でそのまま表示した場合は、文字コードの変換も行いません。

  プロセス間通信
    socket(2)
    SHELL の章の shell プロンプトで、プログラムの出力を usilic(1) へリダイレクトした場
    合、その usilic(1) (shell の子プロセス) は shell のプロセス ID を含むファイル名の
    socket(2) を作成して、自分にリダイレクトされた内容を、そこへ書き込みます。一方 shell
    を起動した usilic(1) (shell の親プロセス) が、その socket(2) を見つけた場合、上記の
    リダイレクト内容を、ファイル名「(stdin)」で、その socket(2) から読み込みます。shell
    のプロンプトから file 引数で usilic(1) を起動した場合は、socket(2) の代わりに同じ名
    前の file を使用します。

    pipe(2)
    上記の socket(2) の使用以外では、file の内容をバッファへ読み込む際に fork(2) した子
    プロセスとの間で、pipe(2) によるプロセス間通信を使用しています。

  8.　Key

    8.1.　組み込みのキー

      この節のキーはプログラム内に設定されています (usilicrc の KEY では変えられません)。

      PageDown　　: 画面を１ページ下へ
      PageUp　　　: 画面を１ページ上へ
      Right-arrow : カーソルを１行下へ
      Left-arrow　: カーソルを１行上へ
      Down-arrow　: カーソルを１行下へ
      Up-arrow　　: カーソルを１行上へ

    8.2.　その他のキー

      下記は本文で触れていないキーです (usilicrc の KEY で変えられます)。

      　　^N/^P：カーソルを１行下/上へ
      　　　j/k：画面を１行下/上へ
      ^F/^V/␣：ページ送り (␣ はクイックルックが使えない画面で)
      　b/^B/^[v：ページ戻し
      　^[</^[>：先頭/末尾へ
      　　　^[N：N 行目へ (^[ の後に行番号を入力)
      　　　^X^X：大きく移動する前の行と行き来
      　　　　^L：再表示
      　　　^Oo：ls の表示形式 (詳細/ファイル名のみ) の切り替え
      　　　^O^L：ls のソートキー (名前、日付、サイズ、種類) の巡回
      　　　^Ol：ls のソート順を逆順に
      　　　^Oh：mode-line の表示/非表示
      　　　^X^W：バッファを作業 file (WORK) へ保存
      　　　^[P：直前の CP/MV/ARC で処理した file 名をプロンプトに挿入
      　　　　^Z：サスペンド
